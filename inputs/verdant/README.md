# Verdant Power ADCP Data (Test Case)

[hosseinsz93](https://github.com/hosseinsz93/Verdant-SBU-tidal-project/commits?author=hosseinsz93) used them in his [GitHub repo](https://github.com/hosseinsz93/Verdant-SBU-tidal-project) for tidal analysis of data provided by Verdant Power.

- `ADCP-Data_Deployment-Period1.xlsx` — sheet `Station B`
- `ADCP-Data_Deployment-Period2.xlsx` — sheet `Station B-2`

Read by `dataframe-from-ADCP.ipynb` and `orientation-correction.ipynb`.
